Critical User / System Flows

FlowPathWhy It Matters
Discovery to purchase intentEvents → Event Detail → Notify/Join/Buy ClickCaptures intent even before a sale. Produces event_intent signal.
Verified attendance to pointsCheck-in → trust module → ledger +500 → tier recomputeThis is the cleanest MVP proof of earned fandom.

MVP Build Boundary

Build first:

Event catalog, Home/Events/Rank & Rewards shell (four-tab navigation with crown icon), check-in trust module, append-only points ledger, tier classifier, simple leaderboard, access offer eligibility, challenge-to-reward activation bridge, and basic admin inventory entry.

Defer until partner traction:

Venue POS, live sports data, sponsor ROI dashboards, Snapchat/AR, deep Ticketmaster/AXS partnership features, and predictive churn modeling.

Engineering Translation Notes

Recommended Backend Boundaries

Identity Service: users, connected accounts, privacy, consent.

Event Service: catalog, venue, sale windows, price ranges, status badges.

Gamification Service: ledger, tiers, challenges, ranks, trivia.

Access Service: offers, eligibility, entitlements, redemptions.

Analytics Service: segments, dashboards, partner exports.

API Shape Examples

GET /home?domain=music returns score snapshot, next tier, for-you cards.

GET /events?domain=sports&near=... returns ranked event cards.

GET /rank-rewards?tab=rank returns score summary, leaderboard, challenges, friends activity.

GET /rank-rewards?tab=rewards returns access bar, featured offers, passes, perks by tier.

POST /checkins creates trust evidence and candidate point transaction.

POST /redemptions debits ledger and issues entitlement.

GET /leaderboards?entity_id=... returns rank windows and friend filter.
